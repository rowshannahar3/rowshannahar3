👋 About Me

I'm Rowshan Nahar, a full-stack web developer with a UI/UX design background, based in Chattogram, Bangladesh. I build clean, fast, and user-focused web applications, and I care as much about how an interface feels as how the backend performs.

I'm especially interested in artificial intelligence and deep learning, and in bringing them into real products: from intelligent features powered by LLM APIs to data-driven, adaptive user experiences. My goal is to bridge thoughtful design, solid engineering, and modern AI.

Better Interfaces. Stronger Web.
